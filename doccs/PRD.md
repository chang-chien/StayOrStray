# Product Requirements Document

## Product Name
Stay Or Stray

## Problem
Asian students in UK lack structured financial comparison tools between staying in UK vs returning home.

## Target Users
- International students in UK
- Early career professionals (0–5 years exp)

## Core Problem
Users cannot quantify:
- UK vs home country lifetime earnings
- tax impact
- savings potential
- housing affordability

## Solution
A scenario-based financial simulation engine that compares multiple life paths.

## Core Features
1. Scenario creation
2. Country-based financial assumptions
3. Salary + tax + cost simulation
4. Cross-country comparison dashboard

## MVP Scope
- No result storage
- No AI advisor
- Static calculation engine
- Scenario comparison only
